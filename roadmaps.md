# Skill Mitra Roadmap

## Strategy

Skill Mitra is built in stages. Each stage delivers a useful outcome on its own and strengthens the next stage.

The SIH prototype prioritises the complete evidence-to-hiring loop instead of trying to build every advanced feature at production depth.

## Phase 1: Core evidence-to-hiring loop

### Included modules

- Foundation design system and shared sample data
- Four role-based demo logins
- Student skill assessment
- Assessment results and skill-gap view
- Skill Passport with verification levels
- Industry role requirement builder
- Candidate search with explainable matching
- Opportunities and application tracking

### Outcome

A student can demonstrate skills through assessment evidence, a company can search using verified requirements, and both can see the application/shortlisting journey.

### Why first

This phase proves Skill Mitra’s main differentiator:

> **Hiring can be based on demonstrated and verified skills rather than only resumes and certificates.**

## Phase 2: Career growth and industry learning

### Included modules

- Career Path and target-role readiness
- Recommended projects and next-best actions
- Industry Challenges
- Challenge-based feedback and evidence updates
- Reverse internship marketplace
- Interest requests to companies and mentors

### Outcome

Students do not merely see their gaps. They receive structured paths to close those gaps and earn industry-relevant evidence.

## Phase 3: Ecosystem intelligence

### Included modules

- Academician verification workflow
- Mentee progress dashboard
- Faculty internships, FDPs, workshops, and industry engagement
- Institution dashboard
- Cohort skill-gap analysis
- Department breakdown and placement funnel
- Curriculum insight panel

### Outcome

Faculty and institutions can use shared skill data to guide students, improve programmes, and strengthen placement outcomes.

## Phase 4: Production readiness

### Included modules

- Real authentication and account approval
- Production database and API
- Sandboxed code execution
- Evidence audit logs
- Company approval and challenge moderation
- Notification service
- Privacy controls and security hardening
- Learning-platform and certification-provider integrations

### Outcome

A secure, scalable, multi-institution platform ready for pilots and real users.

## Future vision

- AI mock interviews based on target-role requirements and student gaps
- Skill recommendations using richer evidence and learning history
- Structured internship quality feedback
- Regional-language support
- Low-bandwidth mode
- Cross-institution analytics
- Policy-level employability insights
